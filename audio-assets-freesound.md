# Audio Assets - Buenos Aires 2037 Heat Wave Game

## Instrucciones de Búsqueda en Freesound.org

Para cada asset a continuación:
1. Haz clic en el enlace de búsqueda proporcionado
2. Filtra por licencia (preferir CC0, luego CC-BY)
3. Filtra por tipo de archivo (preferir WAV o FLAC para calidad)
4. Escucha previews y selecciona el mejor
5. Descarga y completa la información en este documento

**Nota sobre licencias:**
- **CC0**: Dominio público, sin atribución requerida (IDEAL)
- **CC-BY**: Requiere atribución del autor (ACEPTABLE)
- **CC-BY-NC**: No comercial, evitar si el juego tiene fines comerciales
- **CC-BY-SA**: Share-alike, puede complicar distribución

## Consejos para Búsqueda Efectiva en Freesound

### Filtros Recomendados:
1. **Licencia:** Filtrar por CC0 primero, luego CC-BY si no hay buenos resultados
2. **Formato:** Preferir WAV o FLAC (mayor calidad)
3. **Duración:** Para loops, buscar archivos de 10-60 segundos
4. **Sample Rate:** Preferir 44.1kHz o superior
5. **Tags:** Usar tags además de búsqueda de texto

### Evaluación de Calidad:
- ✓ Sin ruido de fondo excesivo
- ✓ Rango dinámico apropiado (no sobresaturado)
- ✓ Para loops: verificar que inicio y final coincidan
- ✓ Grabación profesional vs casera (ambas pueden ser buenas según contexto)

### Autenticidad para Buenos Aires 2037:
- Tráfico: preferir grabaciones urbanas reales
- Sirenas: buscar sirenas bi-tonales (típicas de Argentina)
- Voces: preferir español si es posible
- Tecnología retro: sonidos reales de Windows 95 tienen mejor carácter

### Procesamiento Post-Descarga:
- **Loops:** Usar herramientas como Audacity para crear loops seamless si es necesario
- **Ecualización:** Ajustar para consistencia entre assets
- **Normalización:** Igualar niveles de volumen
- **Reducción de ruido:** Aplicar sutilmente si es necesario
