# ENCOUNTERS QUALITY AUDIT
## Evaluación Narrativa de Encounters - Autenticidad y Calidad

**Fecha:** 2025-11-24
**Total Encounters:** 20
**Sistema de Scoring:** 1-5 por dimensión, 4-20 total

---

## METODOLOGÍA DE EVALUACIÓN

### Dimensiones (escala 1-5):

1. **Autenticidad Cultural** - Buenos Aires 2037, lenguaje porteño natural, sin clichés
2. **Trade-offs Significativos** - Opciones con pros/cons claros, no hay opción "correcta" obvia
3. **Consecuencias Lógicas** - Efectos coherentes con elección, flags apropiados
4. **Coherencia Narrativa** - Tono apropiado, personalidad NPC consistente, arco mayor

### Tiers:
- **A (16-20):** Excelente, modelo a seguir
- **B (12-15):** Bueno, ajustes menores
- **C (8-11):** Aceptable, mejoras necesarias
- **D (4-7):** Débil, rewrite prioritario

4. **Consecuencias solo positivas**: No hay dilema real

## RECOMENDACIONES GENERALES

### Para nuevos encounters:

1. **Especificidad sobre vaguedad**: "Motor hace ruidos extraños, caudal bajó 40%" > "hay problemas"
2. **Trade-offs genuinos**: Cada opción debe tener pros Y cons
3. **Consecuencias diferidas**: Flags que afecten encounters futuros (como ayuda_municipal → inspeccion_cierre)
4. **Voice consistency**: Revisar diálogos previos del NPC antes de escribir
5. **Balance check**: ¿Reward >= Cost + (Decay × Days) + Buffer?
6. **3 opciones mínimo**: Más espacio para trade-offs interesantes
7. **Evitar clichés**: "Mate y tango" NO, detalles institucionales SÍ

### Checklist pre-implementación:

- [ ] ¿Diálogo específico (no "situación crítica")?
- [ ] ¿Al menos 2 opciones competitivas?
- [ ] ¿Cada opción tiene pros Y cons?
- [ ] ¿Consecuencias lógicas y balanceadas?
- [ ] ¿Flags se usan en algún otro lado?
- [ ] ¿Voice del NPC consistente?
- [ ] ¿Evoca 2037 o Buenos Aires específicamente?
- [ ] ¿Conecta con arco narrativo mayor?
